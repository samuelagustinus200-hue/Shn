Cara supaya NFC bisa jalan
  • Pakai Chrome di Android (Web NFC belum didukung di iPhone/Safari).
  • Situs harus diakses lewat HTTPS — buka langsung dari file di HP tidak akan bisa. Upload file ini ke hosting gratis seperti Netlify Drop atau GitHub Pages, lalu buka link-nya.
  • Aktifkan NFC di pengaturan HP, dan izinkan permintaan akses NFC saat browser meminta.
  • Yang terbaca hanya nomor seri chip kartu, bukan data NIK/nama di e-KTP — makanya tetap perlu didaftarkan manual sekali di awal.
